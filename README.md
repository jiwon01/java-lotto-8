# java-lotto-precourse
## 기능 요구 사항
- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

## 유의사항
- 제공된 라이브러리 외 외부 라이브러리 사용 금지
- 인덴트 depth 3을 넘어서지 않도록 함
- 3항 연산자를 사용하지 않도록 함
- 함수가 한 가지 일만 하도록 함
- 함수(메서드)의 길이가 15라인을 넘지 않도록 함
- else와 switch/case 예약어 사용 금지
- Java Enum을 적용한다.
- JUnit5와 AssertJ를 이용하여 구현한 기능에 대한 단위 테스트 작성. UI 로직 제외.
- Lotto Class를 이용해야 함

## 구현할 단위 기능
- Lotto 클래스 생성
- 구입 금액 입력 기능 구현
  - 숫자 범위가 1~45인지 확인하는 기능 필요
- 로또 번호 입력 기능 구현 (숫자 5개와 보너스 1개)
- 로또 발행 기능 구현 (구입 금액에 해당하는 만큼 로또를 발행. 개당 1,000원)
- 당첨 번호 추첨 기능 구현
  - 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨 통계 구현
  - 당첨은 1등부터 5등
    - 1등: 6개 번호 모두 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 테스트 코드 작성
  - 구입 금액 입력: 구입 금액이 1,000원으로 나눠 떨어지지 않으면 예외가 발생한다.
  - 로또 번호 입력: 입력한 로또 번호가 범위를 넘어가면 예외가 발생한다.
  - 로또 발행 기능: 랜덤 숫자 5개와 보너스 랜덤 숫자 1개가 범위 내로 나오는지 확인한다.
  - 로또 추첨 기능: 랜덤 숫자 5개와 보너스 랜덤 숫자 1개가 범위 내로 나오는지 확인한다.
  - 로또 통계 기능: 임의의 당첨자를 배정하고, 로또 통계가 의도대로 나오는지 확인한다.
